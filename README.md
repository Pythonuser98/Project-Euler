# Project-Euler
This repository exists to support my Introductory course to programming, algorithm design, and optimisation techniques.

Additionally, it contains a catalogue of Python code used to acquire the solutions to each of the first 100 problems from Project Euler.

## What is Project Euler?
Project Euler is a website that hosts math- and programming-based challenges that test your mathematical muscles.
The real joy of Project Euler comes from having that "Aha!" moment in solving one of its problems. As such, it is generally discouraged to publish solutions online.
However, an exception is made for the first 100 problems featured on the website. This is to provide an introduction to the types of problems and techniques used on Project Euler.
More information can be found at https://projecteuler.net/about.
